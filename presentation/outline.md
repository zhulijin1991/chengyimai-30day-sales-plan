# 纵向HTML汇报

用户明确调整为连续纵向滚动页面，取代按页翻动的PPT。正文保持多图少字、大白话。

1. 日报：安住每天主动告诉业主新增2位，给出新客户名单后停留并循环；本段不播放短信内容。短信预览与确认集中在下一段邀约动画。
2. 短信：客户名单、平台署名、起始价、房源链接、联系经纪人约看和最终确认均保留。同房源同客户跨轮次仅一次。
3. 阶段复盘：30天示例第10、20天检查；累计2／20、落后23.3个百分点，达到20个百分点才建议。采纳和创建结果留在聊天。
4. 维护人：只一条任务，联系确认方式、具体日期和时间；文字提交后邀约任务结束，实际复盘另行安排。24小时／7天为有效期。
5. 结尾：安住来跟、业主来定、经纪人来约；成交或本轮到期结束推进。

原型不是图片：复用当前原型运行代码，由真实控件完成自动回放。进入视野播放并循环，离开停止。主方案和PRD无修改。
