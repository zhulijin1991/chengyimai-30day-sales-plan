# 诚意卖 · 业主30日销售推进汇报

一张纵向滚动的HTML发布会式汇报页。日报、短信确认、复盘建议、维护人接手分别使用当前原型的真实运行代码，进入视野循环播放，离开后卸载暂停。查看者手动操作后保留当前结果，点击重播可重新循环。

- 原PRD、评论、回复、既有方案HTML均不改动。
- 原型在无同源权限的sandbox iframe内运行，无服务调用、使用iframe内存记录，不共享主方案的短信记录。
- `npm run dev`预览，`npm run package`检查、构建并打包仓库根 `launch.html`。
